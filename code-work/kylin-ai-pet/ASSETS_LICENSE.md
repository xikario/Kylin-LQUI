# 美术素材与来源

- **克劳德大小姐**的 25 段动画、轮廓数据、头像和挥手帧来自 [克劳德大小姐 · Claude-girl](https://github.com/wangxianda941030/Claude-girl/tree/ad6638806254b3024b4d44b402ed2d1926c47713)。美术采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)。本地版对头像做了裁切、缩放和选帧。桌宠代码沿用上游 MIT 许可，见 [LICENSE](LICENSE)。
- **GPT 白龙、Gemini 星空猫**来自 [CrossPet 的角色目录](https://github.com/lokicorvus/crosspet/tree/50691433a7da3a23fdba9a780f7e94378b377f4a/characters)。GPT 白龙的社区原型出自 ZipZipPipe，Gemini 参考社区 AI 拟人设定，立绘由 CrossPet 制作。本地版裁切头像、选取闭眼帧并为猫耳制作悬停序列。这些素材及其衍生图使用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)，附[原作者说明](assets/pets/CrossPet-LICENSE.md)。
- **大肥鱼**的本地素材来自 dsh-pet 7.3.9 源码与说明文档包。动画项目为 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，角色原型「溟月」作者为上善无形，女仆鲸鱼娘设计出自 ZipZipPipe。7 段运行时动画与用于生成侧目序列的原片已按 Git blob 摘要与[上游素材目录](https://github.com/PC2005-cloud/dsh-pet/tree/fb38ce620576f5ed3735a99536d2b1a4a9eb313f/dsh-pet/assets/webm)逐一核对。本地版使用动作节选、裁切头像和侧目序列，角色素材及其衍生图按原作标注的 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 使用。

以上为社区同人形象，角色名称用于标识形象，实际模型由 AI 小站选择。

GPT 白龙和 Gemini 星空猫的桌面扩展动画来自 [hunmer/aboutme-pets](https://github.com/hunmer/aboutme-pets/tree/df864c0c7db75857854740b301f6677e50d0b29c/pets)。作者基于 CrossPet 形象制作动作。本地从两个角色包中各选 18 段，按原帧序和帧率把透明精灵图转换成静音 VP9 WebM，并计算显示范围。素材及转码版本使用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。
