# AI小站

由任务栏小球唤起的液态 AI 对话窗口，支持 Codex、千问 Qwen Code 和 DeepSeek Harness，使用 Qt5 原生界面。0.2.0 起由终端抽屉改为聊天框。

## 用起来

- **呼出**：点击任务栏日期右侧的 AI 小球打开，再点一次收起。鼠标移入不会弹出。按 Esc 或点别处收起，图钉可以保持展开。
- **状态组合**：日期 → 温度与上下行网速 → AI 小球 → 显示桌面。任务栏未提供入口时，窗口右下角保留一个只响应点击的备用小球。
- **快捷键**：`liquid-cli --toggle` 展开或收起，可绑定到系统自定义快捷键。
- **对话**：Enter 发送，Shift+Enter 换行。回复以 Markdown 显示，右键可复制。
- **问答模式（Codex）**：普通思考沿用原模型与强度；快问快答可独立选择模型、思考强度和 Fast，未配置时仍为 `gpt-6-luna / low`、Fast 关闭。聊天、草稿、图片和线程单独保存在 `quick-reply/`。窗口按钮可临时切换，不改普通模式的模型设置。回复、压缩或截图期间不能切换，保存失败也不会丢弃当前草稿。
- **快问模型配置**：`quickModel`、`quickReasoningEffort`、`quickFast` 即时保存，下一条快问消息生效；普通模式和全局 Codex 配置不受影响。模型和思考档位来自模型目录；Fast 使用目录返回的服务档位 id，经 `turn/start.serviceTierForTurn` 发出，关闭时显式发送 `default`。目录不支持 Fast 时不会静默降级。Fast 可能增加额度消耗，服务端可用性与实际提速需要分别验证。
- **普通思考 Fast**：`normalFast` 独立保存，默认关闭；下一条普通消息生效，关闭明确使用标准档位。两种模式的 Fast 开关互不影响，均不修改全局 Codex 配置。
- **手动使用技能**：两种模式均将输入原样交给 Codex，不关闭技能或工具。例如可输入“加载 AI 空间 skill，按技能检索本地资料”。技能发现、是否可用和执行权限沿用现有 Codex 配置；快问模式不会为提速删除这类明确指令。
- **默认问答模式**：设置中可选“快问快答 / 普通思考”，即时保存，下次启动生效。未配置时仍为普通思考；当前对话不因修改默认值而切换。配置字段为 `defaultReplyMode`（`normal` / `quick`）。快问的压缩提醒最多为 64K，只提醒，不会自动清空或压缩。
- **输入中…**：推理过程、模型的过程旁白、执行命令等都只显示为“输入中…”。回复结束后，下方用一行小字注明“运行 N 条命令 · 修改 N 个文件 · 用时”。
- **停止**：回复期间发送按钮变为停止键。
- **新对话**：顶部“＋”为当前模式开启空白对话，旧记录及其附图保存到该模式目录的 `archives/`，保留原线程编号；另一模式不受影响。输入框内的草稿可继续用于新对话。回复、压缩或截图期间不可新建，归档失败时保留原对话。
- **图片**：截图按钮先隐藏侧边栏再框选，也可以直接粘贴或拖入图片。图片附在下一条消息里，不会自动发送。
- **每个后台一个对话**：Codex 的聊天记录和附图继续保存在 `~/.local/share/liquid-cli/`，千问和 DeepSeek 分别使用其中的 `backends/qwen/`、`backends/deepseek/`（文件仅本人可读）。各自保存会话编号与草稿，切换回来可继续原对话。如果线程无法恢复，会提示并从新上下文继续，聊天记录不受影响。
- **压缩提醒**：标题栏显示当前上下文用量。超过阈值（默认 256K）时，对话下方会出现提示，由你决定立即压缩还是稍后。Codex 调用自己的压缩接口；ACP 后台仅在声明压缩命令后开放此操作，聊天记录不变。
- **审批**：执行权限默认跟随 `~/.codex/config.toml`。只有 Codex 请求审批时才会出现“允许 / 本次对话都允许 / 拒绝”卡片。设置里也可选“每次询问”“工作目录内自动”“完全放开”。
- **空闲休眠**：默认 10 分钟没有对话活动就关闭 Codex（约 0.5 GiB，含它带起的 MCP 服务），下一条消息自动接上同一个线程。设置里可改时长，0 为不休眠。
- **清空**：在“设置 → 清空聊天记录并开始新对话”中操作，会二次确认。

打开聊天窗口不会启动后台。发出第一条消息时，才在受守护的 systemd scope 里启动所选 CLI。退出、清空或宿主崩溃时，整个 scope 连同其中的子进程一起回收。

## 独立运行与任务栏

AI小站是独立程序，由任务栏 AI 小球按需启动。Fences 不再提供显示开关、设置页或随 Fences 启动的联动。

- 点击小球展开/收起，右键设置在小球附近打开。
- 把文件、文件夹、文字、链接或图片拖到小球，内容会追加到输入区。本地文件使用绝对路径，图片另附为图像附件；不会自动发送或启动模型任务。
- 输入框至少三行，内容较多时自动增高至八行，再显示滚动条。拖入后的草稿和正常退出时的草稿会保存，下次启动恢复。
- 每项设置停留一秒显示统一说明气泡；“压缩提醒”最高 765K，此值不扩大模型实际上下文。

## 构建和验证

需要 Qt5 Core/Gui/Widgets/Network/DBus/Test、GL 头文件、Xvfb 与用户 systemd。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
cd build
ctest --output-on-failure
```

CMake 默认使用旁边 `ukui-liquid-desktop/shared/` 的公共渲染与窗口库，可用 `-DLIQUID_DESKTOP_ROOT=/path/to/ukui-liquid-desktop` 指定。以上命令在本组件目录执行；安装器遵循 `settings.json` 中的 `residentOnLogin`（未配置时默认启用）；可在统一设置中关闭登录常驻。

测试使用 `tests/fixture.cpp` 模拟 `codex app-server`：协议相同，不联网，不调用模型。覆盖范围：

- 流式回复，过程旁白不进入回复；
- 线程恢复、无法恢复时新开上下文；
- 截图只附加不发送，图片以 localImage 传入；
- 压缩提示及立即压缩 / 稍后；
- 审批卡片、停止，以及清空和宿主崩溃时的进程回收；
- 浮现动画中途反向、点击呼出与失焦收起规则；
- 设置读写和旧版设置迁移。

```sh
python3 scripts/install.py
~/.local/bin/liquid-cli --show | --toggle | --hide | --settings | --reload | --state | --quit
```

只安装到用户目录，保留旧 release，按已保存的登录常驻设置安装。终端版 0.1.0 的源码保留在 `releases/source-terminal-0.1.0/`。

## 任务栏入口（2026-10-29）

液态任务栏插件通过 `org.ukui.AiStationPanel` 宣告入口；AI小站监测服务出现和退出，自动隐藏或恢复备用入口。小球通过 `ToggleAt(x,y,w,h)` 唤起锚定窗口；冷启动使用 `--show --anchor x,y,w,h`。不轮询 AI 后端，聊天记录、线程 id 和配置继续使用原 `liquid-cli` 数据目录。

入口布局为“温度 / 网速 → 日历日期 → AI 小球”，与左侧麒麟小球对称。显示桌面入口位于屏幕右下角。

任务栏温度每 10 秒读取内核传感器；网速每 2 秒读取真实网卡计数，排除 TUN、回环和虚拟桥的重复流量，接口变化或计数器重置时重新建立基线。网速是当前传输速率，并非线路的带宽上限。无 CPU 温度传感器时仅显示真实 ACPI 机温；没有有效传感器显示破折号。小球无常驻动画。

## 模型与外观设置

模型版本来自本机 `codex app-server` 的 `model/list`，强度列表随模型变化，不写死版本和强度。打开设置会短暂读取目录和有效配置，随后释放该查询进程，不创建对话、不发送消息。设置明确显示“下一条消息”使用的模型与强度，CLI 默认值另列为仅供参考，并随选择实时更新。选择后即保存并用于下一条消息；选“跟随 Codex”时，每次发送重新读取 CLI 默认配置。原有对话无需重新开始。

所有数值使用横向滑块。字体、输入提示、链接、代码块和按钮图标按玻璃背景统一对比色；设置也使用壁纸玻璃背景。左麒麟与右 AI 的短光晕/微光仅在进入和点击时播放约 420ms，局部约 30fps，结束后动画对象停止、覆盖层隐藏。

## 千问与 DeepSeek 接入

设置中的“AI 后台”可以选择 Codex、千问 Qwen Code、DeepSeek Harness；点击“应用”切换。正在回复时先停止当前任务。启动命令、模型、思考强度和会话模式分别保存，原有 Codex 设置与记录自动沿用。

| 后台 | 默认命令 | 小站自动添加的协议参数 |
|---|---|---|
| Codex | `codex` | `app-server` |
| 千问 Qwen Code | `qwen` | `--acp` |
| DeepSeek Harness | `dsh` | `--profile acp` |

使用前自行安装对应官方 CLI 并完成其登录或模型提供商配置。小站沿用 CLI 的凭据与环境，不代装 CLI，也不读取、复制账号令牌。自定义启动命令只填写程序及必要的其他参数，协议参数由小站添加。

ACP 接入使用官方协商的能力与配置：

- 模型、思考强度及会话模式来自 CLI 的配置选项，支持分组模型列表与依赖模型的强度变化，不写死模型版本。
- 刷新设置会创建一个查询用会话，读取配置后关闭连接，不发送用户消息；查询会话的持久化由 CLI 管理。选择“跟随会话配置”会保留该 CLI 会话已有的配置。
- 恢复优先使用声明的 `session/resume`，旧版支持时使用 `session/load`；加载时不重复展示 CLI 回放的旧消息。只有确认旧会话不存在或接口不支持时才新建；登录和其他恢复错误会保留原编号并提示。
- 工具授权按 CLI 提供的选项原样显示，保留一次允许、拒绝及其实际授权范围。停止时取消尚未作答的授权。
- 本地图片以 MIME 和 base64 图片内容发送；后台未声明图片能力时会提示，不会把图片当作已识别文本。文件拖入仍保留绝对路径。
- 上下文用量使用 ACP `usage_update`。只有 CLI 声明 `compress` 或 `compact` 命令后才提供压缩按钮。DeepSeek 官方 ACP 当前不提供模式或压缩命令；它传回已提交的消息，不保证逐字输出。
- 各后台沿用按需启动、空闲退出和整组子进程清理。没有启用语音功能。

接入依据：[Qwen Code 官方架构](https://qwenlm.github.io/qwen-code-docs/en/developers/architecture/)、[DeepSeek 官方 ACP 合约](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/acp/acp/README.md)、[ACP v1 协议](https://agentclientprotocol.com/protocol/v1/overview)。

`tests/acp-fixture.cpp` 是离线协议对端，覆盖两种启动参数、分组模型与强度切换、图片编码、授权与停止、两种会话恢复方式及历史回放过滤；不登录账号、不调用真实模型。本次接入没有执行真实千问或 DeepSeek 联调。

## Kylin-LQUI 0.2.2 · 登录常驻

`--resident` 只保持 GUI 并预热背景，不展开窗口、不连接模型；重复调用不切换界面状态。安装器创建 `~/.config/autostart/kylin-lqui-ai-station.desktop`，设置中的“界面常驻”可改变下一次登录策略，模型后台休眠是独立选项。面板重新出现时会更新隐藏背景预热位置。

任务栏小球真实 Xdnd 图片拖入只协商 Copy，进入草稿并保留原图；文件记录绝对路径，不自动发送。聊天、草稿和后台会话按原配置位置保留。
