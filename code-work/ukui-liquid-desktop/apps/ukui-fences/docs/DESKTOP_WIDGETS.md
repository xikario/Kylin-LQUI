# 桌面小组件：时钟、活动、音乐与日历

本文说明四类 LiquidDesklet 卡片；另见 [系统监视](SYSTEM_MONITOR.md) ；原智能空间现为[独立AI空间](https://github.com/xikario/ai-space)。这四类卡片及系统监视由 Fences 承载，无需安装 Quickshell 或替换系统桌面。

设计参考 NextKde DeskCenter，来源提交和许可见 [NextKde 小组件来源](../vendor/nextkde-desklets/README.md) 和 [第三方声明](../../../THIRD_PARTY_NOTICES.md)。

## 入口与布局

在桌面空白处右键 → **桌面小组件**，勾选对应组件；在 **Fences 设置 → 桌面小组件** 单独设置随 Fences 启动。当前显示不等于已开启自启动。

开启 **编辑分区布局** 后拖动卡片标题移动、拖动右下角缩放；完成后 **退出布局编辑**锁定几何。距屏幕边缘或相邻组件较近时吸附，首次放置尽量避开已有分区和组件，屏幕变化后约束到可见区域。桌面图标会避开可见卡片；组件移动、显示和隐藏后重新检查布局。

四类卡片没有右上角关闭按钮。使用卡片右键 **隐藏组件**，或桌面小组件菜单取消勾选。隐藏不清空配置和数据；音乐继续播放，活动统计是否继续由记录开关决定。

## 时钟与倒计时

默认时钟卡片为 220×250 逻辑像素，显示指针钟、数字时间与日期。倒计时可选 **5 / 15 / 25 分钟**，或输入 **1–1440 分钟**；开始后可暂停、继续和取消，到点发桌面通知及提示音。

截止时间、暂停剩余时间与页面状态会保存，Fences 重启后恢复，到点只通知一次。倒计时不是独立后台提醒服务：如果下一次登录没有启动组件，它就不会在未启动时通知。时钟和倒计时操作保留在卡片本体，显示和自启动在设置中心管理。

## 活动统计

默认 360×220 逻辑像素，显示最近 60 天开机时长和今日前台应用排行；右侧展示前五应用，更多记录可在详情页查看。

开机时长来自 `/proc/uptime`，首次启用能读取本次开机的时长，包含锁屏及休眠。应用统计从启用记录开始，不补造过去使用历史；前台停留时间也不等于有效工作时间。

仅累计 WM_CLASS 对应的应用名称和时长，不读取窗口标题、文档名、键盘输入。锁屏、暂停、本程序及桌面/任务栏等不计入应用时长。隐藏卡片仍会记录；用卡片的 **暂停记录** 或 **Fences 设置 → 活动统计**关闭记录。开机累计继续显示。

数据默认保存在 `~/.local/share/ukui-fences/widgets/activity.json`，跨午夜分日、同一开机身份增量记账，Fences 重启不会把同一段开机时间重复累计。更新采用定时保存与正常退出保存，不是连续写盘。

### 资源指标、历史与日志

应用行停留 1 秒显示前台时长、当前 CPU/RSS、今日采样均值与峰值；点击应用或“查看记录”可按日期查看完整汇总并导出 CSV。旧时长记录自动备份后升级，不补造过去的资源数据。

默认每 10 秒异步采样今日前五应用可关联的窗口进程及子进程，排除重复祖先归属。CPU 按单核 100% 计；RSS 为进程组之和，共享页可能重复。均值只覆盖有效采样的运行时段，不代表整天平均，峰值也不是未采样瞬间的硬件峰值。进程刚出现、PID 复用、休眠或过长采样间隔会重建基线。

Fences 设置 → 活动统计提供资源采样开关、5–60 秒间隔和 1/3/7/14/30 天日志保留。暂停记录或锁屏会停止资源采样；隐藏卡片继续遵循记录开关。汇总始终保留最近 60 天；详细指标每分钟批量写入 `~/.local/share/ukui-fences/widgets/activity-metrics/YYYY-MM-DD.jsonl`，默认保留 7 天，只有到期的日期日志会自动清理。详情中的“打开指标日志”可查看文件。

`activity.json` 使用 schemaVersion 2；首次从版本 1 升级会保留 `.v1-*.bak`。汇总原子保存、日志仅当前用户可读写；写入失败会在卡片显示提示。不会记录窗口标题、文档名称、命令参数或输入内容。

## 音乐播放器

默认 360×180 逻辑像素，通过 MPRIS 展示客户端、封面、歌曲、歌手、进度和音量，支持播放控制与前置播放器。首次建议手动启动客户端，在 **Fences 设置 → 音乐播放器** 添加检测项并应用。

仅自动接入已启用的客户端；多个同时运行时选择最后启动的，退出后回到其他候选。完整的识别步骤、手动字段、选择规则、能力限制和故障排查见 [音乐配置与使用](MUSIC_PLAYER.md)。

可见且播放时显示五个矢量音符，约 30 帧/秒，刷新卡片内的音符区域并复用玻璃缓存；暂停、隐藏或客户端退出后停止。动效概念参考 [Groove Index 的 Floating Musical Notes](https://github.com/NainaKothari-14/groove-index/blob/main/README.md)，使用本项目 Qt QPainter 绘制，未引入其代码、素材或网页运行时，不分析音频节拍。

## 日历与系统待办

折叠时，日历右下角用小字显示「！」提醒，左下角保留「休：放假　班：调休上班」。默认预览今天未完成的事项，点某个日期后改为预览当天，每行显示时间和简短内容，最多两行、每行最多 10 个字符；点开后可看完整内容。折叠尺寸默认 400×270 逻辑像素，展开默认 400×464，可保留用户调整后的展开高度。

点「！」展开选中日期的待办，也可用右上角加号展开列表。单击选中事项，再用下方 **完成 / 恢复、编辑、删除** 操作。**全部** 优先显示今天和旧的未完成事项，已完成的排在后面。点击某一天按日期筛选，双击事项或点 **系统日历** 可查看原日程。点击年月可用滚轮选择器翻月；今天以日期高亮提示。日期有待处理事项时显示琥珀色；没有待处理事项、但有待审核事项时显示紫色；全部完成显示青色。

### 待办来自哪里

系统待办来自 `$XDG_CONFIG_HOME/.kylin_calendar_Schedule2.db`（默认位于 `~/.config/`）。普通日程的完成状态保存在桌面设置里；重复事项按当次完成，可以在展开列表恢复。带有「【工作待办】#编号」的事项按工作待办编号读取中台状态。已接收或进行中的工作待办可填写验收说明并**提交审核**；只有中台报告审核通过才显示「已完成」。卡片可见时约每 30 秒刷新中台状态，提交后立即应用中台返回的状态。待审核和已完成事项保留最后一次导入的日历位置，即使同步清理了原日程。

普通日程的编辑和确认删除会写回原系统日历事项。工作待办的内容和删除由中台管理。单日、不重复的公历事项可修改日期、开始时间和结束时间；重复或其他特殊事项可编辑内容，时间和规则仍可在系统日历调整。编辑重复事项内容或确认删除会作用于整组，界面会提示。保存前核对原事项是否已被其他程序更改；遇到冲突时刷新列表。

单次事项可在 **全部** 中查看历史。重复事项按所选月份及今天前 30 天 / 后 90 天展开；翻月或点选日期后，摘要会跟随选中日期。系统日历的文件变化会触发刷新；卡片可见时每秒检查一次文件状态，漏掉通知也能补刷，文件没变就不会反复读取。读取失败时保留上次内容并重试。完成和审核状态都不修改系统日历的提醒设置。

### 农历、放假与调休

农历通过系统 ICU 计算；源码随附 **2026 年** holiday-cn 数据，其他年份不推断官方调休。卡片右键 **同步最新农历和节假日**，或设置中心日历页同步，可通过 HTTPS 获取当前、所选和下一年的已发布数据。验证后原子保存，未发布、空占位或网络失败均保留旧数据，不上传系统待办。

## 材质与验证

四类卡片共用 [公共光学材质](../../../shared/liquid-glass/README.md) 和 [公共菜单](../../../shared/liquid-popup/README.md)，从 DesktopCanvas 缓存取壁纸，位置、大小或背景变化时更新材质。时钟、进度和统计刷新内容，不逐次重算底板；没有额外常驻 UI 进程或连续桌面截图。

相关隔离测试为 `desktop_desklets_*`、`desktop_music_*`、`desktop_calendar_*` 和 `calendar_snapshot`，使用独立 Xvfb / D-Bus / XDG 数据。操作方法及验证限制见 [构建文档](../../../docs/BUILD.md) 和 [验证记录](../../../docs/VALIDATION.md)。
