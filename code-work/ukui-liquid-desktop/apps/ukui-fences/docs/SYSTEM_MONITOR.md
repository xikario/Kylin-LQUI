# 系统监视与本地资源快照

系统监视与 Fences 共用一个进程，展示 CPU、内存、主目录分区、进程排行和本地资源概况。DeepSeek 诊断、模型列表、密钥输入、密钥环读取和云端请求已移除。需要 AI 分析时，可复制快照后粘贴到独立 AI 小站。

## 布局与交互

上方三张卡片显示 CPU、内存和磁盘容量及最近采样趋势，CPU 卡片包含逻辑核心负载。下方宽表展示前五进程；资源概况展示 CPU/内存采样峰值、1 分钟系统负载、交换内存、整盘读写速率和采样时间。结构参考 NextKde 的指标与趋势分层，不增加独立仪表盘服务。

- 点击“紧凑模式”收起下半部分，双击标题也可切换。
- 右键可选择 CPU/内存排序、复制单进程指标、查看或导出资源快照。
- “查看详情”显示打开时的只读快照；复制和导出同一份显示内容，不在阅读时改写选择。
- 仅编辑模式允许移动和缩放。显示、随 Fences 启动及专项配置均在 Fences 设置中。

## 指标口径与资源策略

整机 CPU 为全部核心的平均占用，范围 0–100%；进程 CPU 按单核 100% 计，多核进程可以超过 100%。进程身份包含 PID 与内核启动时间，PID 复用不会沿用旧计数器。首次没有基线时显示“—”。内存为 RSS，不同进程的共享页可能重复。

内存已用基于 MemTotal−MemAvailable；磁盘容量对应主目录所在分区，读写速率统计物理整盘，不重复加总分区。趋势和峰值覆盖最近最多 60 次实际采样，持续时间随采样间隔和桌面遮挡而变，不能视作固定一分钟或进程生命周期峰值。

默认每 5 秒采样；读取在后台完成，隐藏组件停止采样，桌面被普通窗口完全遮挡时降为至少 30 秒。没有刷新动画循环，也不为每次采样重建液态材质。

## Fences 设置

**系统监视**页可配置皮肤、标题、字体、字号、透明度、采样周期、进程排序、紧凑视图和卡片光感，修改表单后点“应用”。**桌面小组件**页管理显示与自动启动。

不再读取或修改旧 API 密钥；历史凭据保持原位供用户自行管理或回退。旧版诊断实现的带日期文档属于历史记录，不代表当前功能。
