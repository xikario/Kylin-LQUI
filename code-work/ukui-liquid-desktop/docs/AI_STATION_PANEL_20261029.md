# AI小站与任务栏状态组合 — 2026-10-29

## 本轮基础

基于本机已经完成的 0.2.0 原生聊天版继续修改：保留单一对话、Codex app-server、记录与线程恢复、截图仅附加、审批卡片、压缩提醒、10 分钟空闲休眠和 scope 回收。未还原为早期 QTermWidget 终端版。原配置、历史和 D-Bus 名称仍兼容。

## 入口与布局

- 对外名称统一为 **AI小站**，应用图标换为蓝紫色小球。
- 取消鼠标移入自动展开；点击才展开或收起，Esc/失焦与固定逻辑保留。
- 真实任务栏内部顺序：日历日期 → 温度和上下行网速 → AI 小球 → 原生显示桌面。
- 在原生 showdesktop 插件的公开 Qt 布局中加入子控件，兼容单格 QGridLayout 与 QBoxLayout；不使用覆盖窗口、不读取私有对象偏移，不改系统二进制。
- 原生显示桌面按钮仍是原来的控件；数据变化不会改变组合宽度。
- 面板提供 org.ukui.AiStationPanel 服务，AI小站据此隐藏备用入口。面板退出或不支持此横向布局时，备用小球恢复；点击小球冷启动后，使用同一单实例聊天进程。
- 当前组合针对顶部/底部横向任务栏；垂直任务栏隐藏组合，使用独立备用入口。

## 参考与实现边界

参考 NextKDE 3fa1d7006869bbd3404a05d362c6e6028e0fe3da 的紧凑双行温度与网速表现形式，Qt5 原生重新实现。未引入其 Qt6/Quickshell/独立数据服务依赖。

- [CpuTemperature.qml](https://github.com/NextKde/NextKde/blob/3fa1d7006869bbd3404a05d362c6e6028e0fe3da/shell/desktop/modules/bar/CpuTemperature.qml)：当前均温与最近五分钟峰值。
- [NetworkTraffic.qml](https://github.com/NextKde/NextKde/blob/3fa1d7006869bbd3404a05d362c6e6028e0fe3da/shell/desktop/modules/bar/NetworkTraffic.qml)：固定宽度上下两行，数字变化不挤动其他图标。

小球为本项目绘制的 AI 标识，不宣称复刻 NextKDE 的 AI 产品。无常驻光效动画。

## 资源与数据口径

- 网速每 2 秒读取 /proc/net/dev，以单调时钟计算实际传输率。仅统计有真实 device 的活动网卡，不叠加 Clash/TUN、回环、虚拟桥。
- 首次采样、接口变化、计数器重置和长时间挂起后重新建立基线，不显示虚假峰值。
- 温度每 10 秒读取内核传感器。优先 CPU 类传感器，只有 acpitz 时标注“机温”，绝不把 GPU、磁盘或电池温度当作 CPU 温度。
- “峰值”为最近 5 分钟采样均温的最大值，并非硬件记录的瞬时最高温。
- 标签固定宽度，仅数据文本变化时局部重绘；面板隐藏时停止采样。没有 shell 命令、外部监控进程或后台 AI 调用。
