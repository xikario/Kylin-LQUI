# 协调桌面材质与全局图标主题（2026-10-31）

本轮承接 NextKde Dock 参考图的整体协调要求，并加入自动图标适配、三套图标主题。主题覆盖任务栏应用、桌面/分区、开始菜单，以及麒麟开始菜单球和 AI 小球。保留原应用标识，不改写应用提供的图标文件。

## 视觉与入口

- 原彩圆角：保留鲜明品牌色，自动规范画布、留白和圆角。
- 轻透玻璃：蓝灰透明底色、细边反光；两端小球同步使用清透蓝色光感。
- 柔和雾面：低对比底色和柔和反光；两端小球同步使用灰蓝雾面。
- 设置路径：任务栏与 Dock → Dock 与托盘 → 应用图标。关闭“统一应用图标与两端小球的主题”可恢复原始图形。
- 桌面图标设置有“全桌面图标主题…”跳转入口；原有单独玻璃底板偏好保留，统一主题关闭后生效。

桌面小组件、分区、开始菜单、AI 窗口、任务栏和融合控制中心采用协调的中性玻璃基线，降低边缘高光；阅读窗口使用更强的背景扩散和压暗，保证文字对比度。小组件通过内部绘制留出间隙，不移动已保存的位置。Dock 使用 61% 的居中长度，固定附件结构不变；温度/带宽/日期组合没有拆开，两端小球大小和相对附件位置保留。整条 Dock 收窄居中后，其绝对屏幕坐标随之变化。

## 实现与资源

`shared/icon-style/` 为三个原生界面共用的适配层：

1. 从主题请求高分辨率或矢量栅格，分析透明留白、形状比例、覆盖率和角点。
2. 已有完整方形底板的图标保留原设计并统一外轮廓；圆形、长条和不规则标识按原比例放入统一画布。
3. 白色标识自动使用较深底色；保留中心色和应用辨识度。
4. 根据图标身份、像素尺寸、状态和主题缓存结果；缓存未命中时才分类、绘制。
5. 配置位于用户 `kylin-lqui/appearance.ini`，键为 `icons/uniform`、`icons/theme`。使用文件变更通知同步进程，没有常驻转换进程、目录扫描或周期性渲染。
6. 桌面拖动预览与开始菜单图标缓存包含策略版本，切换主题后即时刷新；原文件未修改，可恢复。

主题颜色集中在 `IconTheme.h`，便于以后扩展。此版本是三套内置主题，不包括任意第三方主题包导入。对只有小位图的应用，适配层不能凭空恢复缺失细节；优先使用原应用提供的矢量或更大尺寸资源。

## 重排与局部绘制修复

缩窄 Dock 后，原生任务栏按旧图标尺寸判断溢出，反复显示双翻页箭头；适配层立即隐藏箭头，导致 Show → Hide → LayoutRequest → realign 循环。此前本机打开设置时 panel 约占单核 82%。现在让原生箭头保留内部显示状态，但设为零宽、不绘制、禁用输入；原生窗口激活、固定应用、溢出菜单和退出适配后的恢复仍保持。

新小组件边缘内缩后，系统监视器的鼠标高光局部刷新区域也同步使用新圆角，避免局部重绘残留。裁切图标的淡化检测改为核验整个实际画布的透明度，而非依赖旧玻璃底板位置。
