# 固定空间内的 Dock 自动缩小（2026-10-31）

按用户最后确认，默认不改变现有居中任务栏的长度和位置。应用增多时，应用图标与间距继续按比例缩小，始终优先维持单行完整显示；移除“⋯”入口和长列表，不采用横向滚动。温度/带宽/日期组合、系统控制区、麒麟和 AI 小球保留原尺寸和位置。

## 默认与设置

- 保留当前 61% 基础长度。更新前后实机面板位置和尺寸均为 `(561,1728,1758,72)` 物理像素。
- “应用增多时自动延长”默认关闭，只有主动开启才在基础长度与指定上限之间按应用数量调整；上限默认 98%。关闭后恢复原设定长度。临时长度通过原生非保存接口设置，不改写用户的基础长度。
- “鼠标悬停时放大图标”默认关闭。开启后只改变图标绘制大小，不改变任务栏长度、单元格或信息区；减弱动画时停用。移动停止后不保留动画计时器。
- 设置集中在统一设置 → 任务栏与 Dock → Dock 与托盘。基础长度、自动延长、延长上限、悬停放大的说明均可悬停查看。
- 自动隐藏沿用现有系统配置，本轮不修改。

## 实现

`DockLayoutMath.h` 取消原来 26px 下限触发溢出菜单的规则，按可用应用区域求解图标尺寸，间距和留白随尺寸变化。整数栅格仍需最小像素；应用极多时图标会很小，需要用户整理固定项或窗口。

`PanelDockCompat` 保留 OEM 应用分组、真实窗口按钮、固定/激活/最小化与拖放路径，仅控制单元格布局。原生分页宿主宽度为零、禁用输入和绘制；水平/垂直滚动条不可见，应用区没有隐藏的滚动范围。滚轮不会进入旧分页逻辑。保留前一轮宿主重排去重，静置不循环。

可选自动延长通过 `PanelLayoutCompat` 管理，延长时复用玻璃缓存，结束后重新准备一次材质，避免每个动画帧重新模糊壁纸。固定附件宽度在长度动画期间使用稳定测量值，避免布局反馈。关闭适配时恢复原尺寸、间距、滚动条策略和原生操作。

## 验证

- 真实 OEM / 私有 X11、会话总线和临时配置：14、18、26、39 个图标在相同宽度内显示，示例图标尺寸依次为 31、25、17、11 逻辑像素；关闭演示窗口后恢复。
- 完整原生集成用例验证到 79 个应用：保持同一行，所有按钮位于应用区内，总宽度及固定附件不变，没有更多入口、滚动范围或静置重排循环。
- 可选自动延长和悬停放大的开关、几何边界和恢复检查通过；悬停放大静置后无持续帧计时器。
- 100%、150%、200% 缩放的实际 OEM 演示通过；原有布局兼容 1/1.25/1.5/2 DPR 及 Dock 绘制 1/1.5/2 DPR 共 7 项通过。
- 系统控制、三套图标主题、日历右对齐、隐藏托盘、通知历史、点击反馈、适配恢复及统一设置路由通过。
- 实机仅更新任务栏插件。原生宽度、百分比、对齐和自动隐藏配置核对未变；AI 进程未重启。
