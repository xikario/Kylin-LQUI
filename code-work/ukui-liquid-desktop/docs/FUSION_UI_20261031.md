# 2026-10-31 · 融合式设置、控制中心与原生日历

本轮对应用户指出的三个问题：顶部标题和操作区域分裂、控制中心未形成统一液态卡片以及隐藏托盘出现滚动条、日历未与任务栏右对齐。

## 已交付

1. **统一设置头部**：窗口标识、搜索、主页和最小化／最大化／关闭位于同一客户区顶部。保留常规黑色线条按钮，支持拖动、双击最大化、还原、关闭和尺寸调整；移除了额外的系统装饰标题条。
2. **底部统一控制中心**：网络、声音、电池和通知入口打开同一份液态卡片总览。Wi-Fi、蓝牙、媒体、显示设置、勿扰、显示亮度、声音、通知历史、电池和会话操作集中呈现。网络列表、配对、输出设备、电源模式、锁屏／睡眠／休眠／注销／重启／关机均保留相应入口；不支持的硬件能力如实显示不可用。会话操作需要用户在界面内确认，取消不发出命令。
3. **隐藏托盘**：采用实际图标与布局最小尺寸计算弹层高度，消除普通数量图标产生的裁切及右侧箭头滚动条。大量图标超出屏幕时仍可滚轮浏览；没有删除图标。
4. **完整原生日历**：复用 UKUI LunarCalendarWidget，保留农历、日程查看和编辑，向上弹出并对齐任务栏右边缘。控制中心也可以打开同一个原生日历。

温度／带宽／日期组合圈、两端小球、显示桌面的位置未调整。AI 小站进程没有重启，对话和草稿未修改。stock-code 未修改。

## 材质与资源

参考 [NextKde 控制中心组件边界](https://github.com/NextKde/NextKde/blob/main/shell/desktop/modules/bar/controlcenter/README.md) 的组合方式：一份面板承担定位、交互与状态，卡片承担展示，详细设置从卡片进入。

使用一次开窗截图生成缓存的模糊背景，各卡片从同一背景取材并绘制细边高光。没有持续截图或逐帧模糊；收起后释放背景并停止轮询，隐藏空闲 60 秒后退出控制中心。网络、音频、蓝牙、显示和电源均复用系统服务。

显示亮度通过 UKUI 用户会话 GammaManager 调整画面。此 OEM 对硬件亮度系统服务有限制，没有绕过其权限；硬件背光和其他显示选项仍可从“显示设置”访问。

## 通知历史边界

最近通知由已有 Panel 进程订阅 UKUI 的通知信号，不另起常驻记录进程。只保留最近 200 条，文件权限 0600；支持去重替换、分页和清空。可以在“任务栏与 Dock → Dock 与托盘”关闭“保留最近通知”。

UKUI 现有接口没有导出接入前的完整历史列表，因此没有伪造或清空旧历史。较早通知保留在“系统通知”入口；新接入的记录在融合面板中查看。通知正文只用于文本展示，不执行其中的命令或链接。
