## 语音：已核查，但未接通

按用户最后一次更正，**没有将单独 OpenAI API 密钥方案作为默认接入**。

- 当前 Codex 桌面客户端 26.928.21956 的本地录音自动停止计时器是 **595 秒（9 分 55 秒）**。已在 AI 设置中显示参考版本和可用性。这不是公开的服务端上限保证。
- Codex CLI 0.165.0 的实验性实时语音启动，对现有登录明确返回 `realtime conversation requires API key auth`。
- 当前 Linux 客户端的可选全局听写扩展，26 个单元测试通过，但补丁不匹配正在安装的客户端源码，按失败即停止的规则没有应用。
- 先前私有兼容接口的 403 未被绕过或反复重试，原型已移出产品目录。未采集用户麦克风，没有无效的“已接通”按钮。

后续可继续适配客户端原生全局听写，再把结果送回输入框；需要独立构建、客户端退出后的安全切换和真实麦克风验收。详见维护目录 `VOICE_FINDINGS.md`。
