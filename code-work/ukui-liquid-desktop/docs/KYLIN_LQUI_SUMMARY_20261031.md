## 三、已完成的主要功能

### 1. 统一视觉与图标

- 桌面卡片、分区、任务栏、开始菜单、AI 窗口及控制中心使用协调的中性玻璃风格，降低过亮边缘；阅读窗口加强背景处理以保证文字可读。
- 自动裁去图标多余透明留白，统一画布、圆角和视觉大小；圆形、不规则标识自动适配，保留原应用身份和图形比例。
- 三套主题覆盖任务栏、桌面、开始菜单及两端小球：**原彩圆角、轻透玻璃、柔和雾面**。
- 优先使用矢量或大尺寸源，结果按图标、尺寸、状态和主题缓存；原始图标文件不改写。
- 配置变化通过文件通知同步，不增加常驻图标转换程序。

### 2. 任务栏与开始菜单

- 任务栏使用原生 `ukui-panel` 进程内的样式和适配组件，不额外运行第二个 panel。
- 原生开始按钮桥接 V2 菜单，保留点击、右键和 Super 键路径；麒麟球使用抗锯齿绘制和手形指针。
- 修复原生布局与自适应布局反复争用；分开处理了“快速点击任务栏空白处闪动”和“快速点击开始菜单时图标左右横移”两种触发方式。
- 开始按钮按住时继续在绘制前校正图标布局，仅任务图标自身的操作保留原生拖动时序。新增复现中错误 Paint 从 182 次降到 0 次。
- 同应用窗口合并后，保留原生预览和切换；关闭可见组首窗口后自动接续其余窗口。
- 按最终要求，拥挤时在固定宽度内缩小图标；关闭多余窗口后恢复大小。
- 显示桌面保留在右下角，以竖线呈现。

### 3. 统一设置与控制中心

- 独立 Kylin-LQUI 设置程序：分组导航、搜索、卡片式表单、材质预览、开关、滑条及延迟悬停说明。
- 标题、搜索和窗口操作融入同一界面，保留常规线条式最小化、最大化和关闭按钮。
- 集中承接 Fences、动态分区、任务栏、开始菜单、AI、输入法、AI 空间与 Peony 设置；原入口定位到对应页面。
- 总览展示模块进程、启用方式、登录启动状态和内存；无法判定的状态不冒充“已启用”。
- 修复页面读取空白、迟到响应、导航缺字、操作按钮分散及切页内容保留问题。
- 底部控制中心集中呈现 Wi-Fi、蓝牙、声音、媒体、亮度、电池、勿扰、通知历史和会话操作，复用原系统后台。
- 控制中心登录后隐藏驻留并做一次预热；隐藏后停止轮询、释放场景和卡片图像，悬停预备过期后也释放。较低首次延迟以约 51 MiB 本机隐藏 PSS 为成本；不支持的硬件能力显示为不可用。
- **快捷设置底部“打开系统日历”按钮及调用方法已移除**。未删除系统日历或桌面日历小组件，也未改任务栏日期组合。原生弹窗的阶段性定位/动画测试记录仅作历史证据。
- Wi-Fi 列表按 ID 原位更新、固定阅读区内部滚动；扫描结果增减不再改变弹窗高度，单个 AP 消失不把整块无线服务判为不可用。
- 长通知正文在阅读区内滚动，保留分页；轮询不重置阅读位置。保存/应用按钮增加按下颜色和轻微位移反馈。
- 说明气泡使用透明圆角窗口和中性底色，去掉四角底板和彩色描边；设置标题左右边界保持一致。
- 快捷设置通过原生桥接使用共享 Snell GPU 材质、真实弹出前场景和有界缓存，CPU 提供回退；异步就绪与动画结束都刷新完整窗口。白底自适应仅由控制中心 context 显式启用，不改变其他调用方的默认输出。
- Wi-Fi 详情进入时自动请求扫描，等待完成代次再刷新列表；Wi-Fi/蓝牙设备行在固定玻璃卡片内滚动。声音页加入输出及非 monitor 麦克风列表、音量、静音和应用流迁移。
- 弹窗可见卡片左侧与下方快捷按钮块最左侧对齐；靠近屏幕边缘时优先保证内容在屏幕内。
- 勿扰开关控制 UKUI 通知弹窗，不清空已有通知历史，也不主动修改音量；第三方应用自有提醒不保证受其控制。
- 隐藏托盘在普通图标数量下完整显示；系统托盘的大量隐藏图标仍有滚轮兜底，此处与应用 Dock 的“不滚动”规则不同。
- 最近通知最多保存 200 条，支持替换去重和清空；接入前的旧历史仍从系统通知入口访问。

### 4. AI 小站

- 前端常驻，模型后台按需连接、空闲退出，降低点击小球后的等待。
- 支持拖入文件、文字和图片；文件使用绝对路径，图片进入草稿，拖放按复制引用处理。
- 输入框放大；修复消息文字对比度、长内容/表格撑宽、窗口右侧裁切及设置弹窗边界问题。
- 模型和思考强度显示实际生效选择；压缩提示可配置到 765K，该值是提示阈值，不代表所有模型都支持同样的上下文容量。
- 截图提供箭头、圆、矩形、文字、直线、手绘及撤销/重做。
- 编辑后的截图放入输入框，由用户手动发送；翻译、文字识别、内容总结直接展示，选择后立即调用 AI。
- AI 窗口与开始菜单共用背景材质，已有聊天、草稿和后台会话分开保存。
- 修复隐藏的统一设置表单阻止失焦收起：仅实际可见的设置窗口参与阻止判断；取消置顶、关闭设置后重新安排收起。截图、弹出菜单和当前输入焦点仍受保护。
- 修复尚未取得 turnId 时无法停止、RPC 确认超时，以及审批长内容显示不完整的问题。
- 支持 Codex、Qwen Code、DeepSeek Harness 的接入代码；后两者做了离线协议测试，**尚未完成真实账号与模型联调**。

### 5. 系统监视器与今日应用

- 系统监视器移除独立 DeepSeek 诊断，保留本地资源展示、进程排行、趋势和快照；AI 分析由 AI 小站承接。
- 增加 Kylin-LQUI 框架进程表，展示主进程 CPU、PSS 和 PID 等信息，区分运行与按需启动。
- 框架状态复用现有进程扫描，没有增加单独扫描守护程序。
- 今日应用保存使用时长；前五应用可查看 CPU、内存采样值、均值和峰值，支持按日期查看、日志与 CSV 导出。
- 提供采样开关、间隔和日志保留期；历史未采集的数据不补造。
- 采样峰值不等于所有瞬间的真实最高值；框架主进程 PSS 也不等于含全部子进程的框架总内存。

### 6. 输入法、AI 空间与文件管理

- 液态候选前端保留 Fcitx/Rime 引擎、词库和输入数据，配置纳入统一设置。配置保存改为异步进程和三份配置事务提交，失败回滚并保留中断恢复记录。
- 输入法前端已改为用户本地版本化安装入口 `~/.local/bin/fcitx-liquid-panel`；不再将开发树中的 build 程序作为当前正式启动入口。
- AI 空间区分“只加载设置服务”和“打开主界面”，修复启动后界面不可见及窗口越界恢复；补上可执行文件确认、文件名纯文本显示、空查询/下划线检索、PDF+ZIP 类型判断和迁移失败检查。
- Peony 全局、终端和扩展设置纳入统一入口，修复名称缺字，软件包归属查询改为批量读取。
