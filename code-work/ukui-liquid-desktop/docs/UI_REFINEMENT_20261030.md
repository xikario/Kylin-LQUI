| 任务栏鼠标经过出现着重底框 | 自适应 Dock 直接绘制图标，去掉原生悬停底框和悬停放大；保留运行状态蓝色标记 | 真实 OEM 面板截图对照；鼠标扫过不启动反馈计时器 |

| 截图编辑窗口过大 | 无标题栏浮动编辑区贴近原选区，不放大小截图；紧凑工具条，按需显示颜色/粗细/文字，AI 三功能归入菜单 | 原六种工具、撤销重做、原分辨率输出、手动附图/立即处理三功能均通过；选区定位与屏幕边界检查 |
| 设置太朴素 | 参考 NextKde 截图重做圆角分组、彩色图标侧栏、材质预览卡、开关和滑条；三个预览卡连接真实材质预设 | 实际安装窗口截图；1040 与 720 逻辑像素宽度检查；高 DPI 检查 |
| 设置空白与其他问题 | 指定页面打开时独立重置请求状态，隔离旧页面响应，加入读取超时；分组点击进入真实页面；修复分区设置入口、禁用选项、多选列表、精确数值、参数名称、最大化状态与未更新文字的切页保留 | 冷启动直达真实面板的材质/布局/动画页均成功；参数与页面检查见下 |
