# AI 小站展开玻璃重绘修复（2026-11-02）

用户报告静止时偶尔透出桌面内容，收起时玻璃恢复。本次处理 AI 小站绘制生命周期；白底材质外观仅分析，未修改共享着色器。

## 修复

`Drawer` 原来以接近空的原生裁剪区域显示窗口，结束时仅取消裁剪，没有补画完整的 Qt 半透明 backing store。材质图片已缓存不代表窗口背景已全部绘制。

现在首次显示先在透明度 0、无裁剪状态下完成布局和整窗绘制，再开始原有移动动画；展开完成后强制归位并完整重绘。关闭动画或减少动画路径同样补画。没有增加逐帧材质生成或常驻轮询。

“已休眠释放内存”来自模型后台停止，未发现该路径释放界面玻璃缓存。

## 验证与边界

- 原有 CTest 在 1、1.5、2 三档缩放下全部通过，覆盖动画反向、后台休眠恢复和记录保留。
- 新增可选原生屏幕测试 `dockGlassBackingStoreIsComplete`：独立 D-Bus、临时配置、52 条合成消息、实际 GPU/KWin 显示，在强制 repaint 之前先从屏幕读取像素，再比较强制重绘后的画面，避免 QWidget.grab 掩盖缺陷。
- 四个场景：首次展开、中途反向后滚动、顶部入口及子控件刷新、禁用动画。修复后四次像素差异均为 0 / 716124。旧代码首次展开仍有 4818 个像素不同，主要在输入区边缘和滚动条；超过本次 0.5% 容差。
- 用户截图中的大片透底未原样复现。上述结果证实并修正了重绘遗漏，但不作为所有偶发合成器问题均已消失的证明。
- 私人桌面、对话截图只保存在 maintenance，仓库仅保存脱敏验证摘要。

## 部署

已安装新的用户本地 release，并通过正常 Quit 重启 AI 小站。52 条消息、上下文、草稿状态及配置保持一致，没有启动模型后台。安装会移除 ELF 的构建 RUNPATH，因此使用独立 cmake install 产物核对哈希；不能直接比较安装前 ELF 的整文件哈希。

## 白底外观建议（尚未实施）

当前宽光带叠加暗化底色，在白底上呈现灰色浮雕；暗底上的高光对比则更自然。纯白背景本身缺少可折射的纹理，单纯增加折射或加深遮罩不能解决。

建议先做局部试样：白底时缩窄并减弱高光，减少内阴影，按整张卡片的低频亮度平滑调整烟色底层和明暗范围；深色背景保留现有光泽。横跨白黑的单张卡片仍保留背景变化，但避免突兀分层。若追求更轻的白底视觉，可另选浅色磨砂玻璃配深色文字，不宜在滚动中频繁切换文字颜色。
