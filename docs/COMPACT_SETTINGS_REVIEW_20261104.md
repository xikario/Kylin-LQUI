## 发现与修复

第一组新增的 12 个用例在修复前全部失败；另单独复现了程序禁用编辑器时意外提交用户文字。修复集中在以下行为：

| 问题 | 修复后的行为 |
| --- | --- |
| 切页前清空搜索，丢失原页搜索状态 | 先按页捕获状态，返回后恢复查询与过滤结果；搜索期间的临时展开在重建后重新应用，清除查询仍恢复用户原展开状态 |
| 编辑/展开下拉/列表聚焦期间跳过回填，后续相同轮询永远不再更新 | 只记录暂缓字段；退出交互后重试这些字段，其余未变化字段仍不更新、不重新解码 |
| 后端把输入归一成原值时，UI 保留了不被接受的本地值 | 提交字段进入待校准集合，即使响应与上次服务端快照相同，也能重新对齐控件 |
| 旧动作回包因 revision/generation 过期被丢弃，按钮不能重新使用 | 内容仍按原版本保护丢弃，动作自身的禁用状态单独释放；切页返回期间继续禁用同一未完成动作，旧回包完成后释放当前按钮 |
| 已重建的旧列表实例还可用复用 runtime ID 发送选择 | 列表提交与其它输入一样检查来源控件实例和页面身份 |
| 成功返回空字段时继续展示上页禁用表单 | 显示当前页的空状态；已有未提交文字不被空响应静默清除 |
| 可编辑下拉忽略原协议 text，且草稿/选区/回执不完整 | 使用原生 currentText，复用行编辑器的草稿与 UTF-16 选区恢复；只清除已提交文字的 modified 状态，保留回执后继续输入的文字 |
| 程序禁用聚焦编辑器触发 editingFinished，意外发送 Set | 服务端批量更新期间屏蔽客户端提交，文字和 modified 状态保留 |
| 元数据把交互字段或说明错误关联到不支持的 owner，或多个输入挤进同一未知 row | 不吞掉字段：非法 owner 局部回退，说明常显；不支持的 row/entity 组合拆成完整的单字段行；非有限数值条件局部忽略 |
| 滑条右键点击也提交 Set | 只有有效左键手势或原键盘动作提交，取消/隐藏/禁用仍不提交 |
| 窗口销毁后收到迟到回包，或恢复光标抢掉输入法新输入 | 回包/排队恢复先检查窗口存活；将 InputMethod 纳入用户交互版本，排队恢复也检查文字未继续改变 |

控件的 runtime ID 和 `Catalog/Page/Set/Activate/Discard` 不变。未加入新服务、预览循环或主动配置写入。新增回归位于 `tests/test_ui_review.py`（17 项）和 `tests/test_ui_schema.py`（增加 2 项）。

控制中心的旧托盘切换用例曾在并发离屏负载下，固定等待 400ms 时读取到仍在运行的动画值 `0.992…`。该用例现等待实际准备/动画状态，保留可见性、完整进度、home 路由和同入口收起的原断言，并有 3 秒上限；没有放宽产品的正确状态断言。
