# 2026-11-02 快捷设置子页自动收回修复

用户实机反馈：点击 Wi-Fi、蓝牙、声音的详情入口，弹窗直接消失。本问题已复现并更新本机安装。

## 原因与修复

`ControlCenter.navigate()` 切页前隐藏窗口，再重建子页并显示。隐藏会产生 `WindowDeactivate`；100ms 后的失焦检查仍可能看到非活动窗口，从而把刚显示的子页收回。这是关闭路径错误，复现中进程仍然存活。

改为在原生窗口内更换内容与尺寸，进入和返回均经过同一导航方法。保持窗口映射、焦点、打开时的场景和材质缓存，不再为内部切页隐藏/重显或重新截图。正常点击外部、Escape、关闭动画、隐藏停止轮询和空闲退出机制继续保留。

此前验证直接调用构建页面和测试打开/关闭，遗漏了真实详情按钮的点击导航路径。新增回归先在旧实现失败，再验证修复实现。

## 验证

- 快捷设置完整 28 项测试通过，新增覆盖 Wi-Fi、蓝牙、声音、电源连续进入/返回，以及后台读取未完成时连续切页。
- 本机 `:0`、已安装发布目录、实际系统后端与 `snell-gpu` 材质，使用真实 XTest 鼠标事件完成两轮四页进入/返回，共 16 次导航点击；所有子页保持显示与焦点。
- 声音输出下拉框展开后，用真实 Escape 键关闭下拉框，详情窗口保持；焦点移到另一原生窗口后，快捷设置仍正常收回。
- 原生窗口 ID 与材质实例保持，卡片缓存上限 32 项；第二轮四页切换材质构建计数保持 32，额外空闲观察也未增加。进程 PSS 约 61.9 MiB，四页预热后约 69.3 MiB；关闭后释放场景。验证进程正常退出，退出码 0。
- 安装保留了已验证的 GPU 退出清理库。桌面布局、任务栏布局/固定图标、开始菜单固定项及聊天文件哈希与更新前一致。旧发布目录保留用于回退。

没有执行 Wi-Fi/蓝牙开关、调音、会话电源操作、模型回复或资料索引。未重启 Fcitx、KWin 或其他主组件。原始非个人数据证据见 [20261102-control-center-navigation](evidence/20261102-control-center-navigation)。
