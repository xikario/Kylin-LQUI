## 行为变化

### 第一次点击

此前隐藏 60 秒后退出，下一次点击要重新加载 Python/Qt、系统适配器和 GPU 上下文；即使把绘制移到动画前，用户仍要等到点击之后才开始准备。

现在加入用户级登录预加载，单实例启动并一次性预热渲染器。隐藏时不持续轮询，不运行渲染循环。任务栏入口收到鼠标进入或键盘焦点时，通过 D-Bus `Prepare` 提前准备背景和卡片；预备窗口为零透明度、无可点击区域，不主动获取焦点。点击时复用同一入口的预备材质，三秒未使用则释放。最近 750 ms 内读到的滑条状态可直接用于首帧，较旧的状态先重新读取。

直接调用且尚无预备画面时仍走正常的准备路径，确保首帧为玻璃。预备画面是入口意图发生时的背景快照，不是持续采样桌面。该改动未调整其他窗口的合成器或重启 KWin。

### 两条滑条

音量和亮度独立于较慢的 Wi-Fi、通知、电源等状态优先读取。初次可见前必须完成当前控制值读取并应用，较早启动的全量读取不能覆盖这些更新的控制值。进场动画和结束后的画面使用相同实际值，不再从默认 0/5 跳到实际位置。

数值标签固定尺寸，禁止换行，避免一位数、三位数及暂不可用文字改变布局。已验证展开到停稳时滑条数值、控件矩形均保持一致。

### 三块等宽

显示设置、电源、勿扰均使用相同玻璃卡片和完整点击按钮，等分一行。当前 DPR 1.5 实机每块为 **121×43** 逻辑像素，间隔均为 **7**；显示设置有文字标签，电源保留暖色图标，勿扰保持可切换状态。
