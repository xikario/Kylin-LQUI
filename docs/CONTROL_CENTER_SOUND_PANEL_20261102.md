# 2026-11-02 整框声音面板与麦克风控制

已把声音子页改为与 Wi-Fi、蓝牙一致的完整玻璃卡片。上半区为扬声器/耳机，下半区为麦克风；设备直接在面板内点选，去掉普通 QComboBox 弹出框。当前设备单独标记，长名称自动换行，较多设备在各自列表内滚动。回声消除设备使用简洁中文标签，提示中保留原始设备名称。

## 功能

- 保留输出音量和静音，输出设备改用列表选择。
- 新增麦克风设备选择、输入音量、麦克风静音/取消静音。
- 输入列表保留物理麦克风和回声消除等输入，排除扬声器 monitor 回录源。
- 调音只在松开滑条或键盘操作时提交；麦克风和输出分开处理忙碌状态，连续拖动保留最后一次请求。旧读取结果不能覆盖较新的静音/调音操作。
- 切换设备时迁移普通应用的相应音频流；回声消除/内部过滤流和扬声器回录流不按普通麦克风录音流迁移。调节静音麦克风的音量不会自动解除静音。
- 麦克风信息在入口准备时读取一次，在声音页显示期间更新；隐藏时不新增持续读取、录音或电平检测。

原有固定位置的页面切换、190 ms 过渡和首次展开逻辑保留。

## 验证

- 60 项 UI/后端测试通过：设备解析、monitor 排除、长名换行、长列表到底、选择确认、设备移除、静音、音量提交/排队、旧读取保护以及原有导航回归。
- 7 项真实 X11/GPU 画面回归通过；补验声音页目标快照与停稳画面一致，防止列表到动画结束后才出现。
- 独立 D-Bus 与 PulseAudio 服务中，仅加载 null-sink/remap-source 等虚拟设备，无 ALSA/udev 硬件模块。实际验证输入音量、静音、静音时调音、默认输入及正在录音的应用流迁移、输出及正在播放的应用流迁移；同时确认回录和内部处理链未被迁移，已移除设备被拒绝。
- 本机只读检查识别到 2 个输出、2 个非 monitor 输入；声音页没有 QComboBox，使用 `snell-gpu`。实际默认输入、输出、音量和静音状态在重新加载前后保持不变。
- 已安装版本通过真实鼠标进入/返回两轮，窗口几何保持 `[1094,485,389,660]`，材质渲染计数第二轮保持不变。
