# 托盘入口连续切换与蓝牙路由合并（2026-11-03）

用户审核两份 x86 补丁后授权合并，要求保留本机此前的修复。本次基于当前提交 432cb3cdd86db2d87c058b327f05ec1330a2eae9 逐项合并，没有覆盖旧版 control_center.py。

## 最终行为

- 在归一到 home 之前保留入口 entry。不同系统入口之间切换时保持展开、位置和玻璃缓存；重复点击同一入口收起。预加载转正、准备过程中换入口、隐藏清理均同步 entry。
- 补齐 ukui-bluetooth 路由。蓝牙位于托盘展开区时也接管左键/键盘主动作，保留原图标几何；先关闭展开区，等合成器移除后再打开控制中心，避免把展开区图标采进玻璃。更新的点击会取消旧的延迟打开。
- 实测发现 Qt 的 MouseButtonDblClick 未被原拦截覆盖。补测在修复前明确失败，现将双击第二次按下按普通左键按下处理，避免漏到 OEM 动作或漏发 Open。
- 为实机验收提供只读 entry 和 systemEntries 状态，包含系统入口的可见性和位置；不读取通知、对话等正文。托盘会动态收起蓝牙，验收使用实时位置，不假定固定像素。

## 保留的既有功能

合并前后 system_backend.py、fusion_view.py、glass_widgets.py、native_glass.py、native_glass_bridge.cpp、volume_feedback.py、audio_events.py 内容不变。control_center.py 保留音频事件监听的启停、试听取消、预加载、动画反向恢复等逻辑。

因此本次没有重写 Wi-Fi 排序/频段去重、麒麟电源模式、麦克风/耳机接口识别、音量反馈或玻璃材质实现。已有 82 项测试连同新增 3 项入口回归共 85 项通过。

## 验证

- 控制中心完整 85 项测试通过（ARM64 / Xvfb / 1.5 倍）。
- 真实桌面 GPU/backing-store 的 7 项测试通过。

- 原生 OEM 面板测试通过，覆盖五入口路由、蓝牙展开区、延迟打开取消、双击、隐藏托盘布局、通知去重、日历稳定和退出/重启用布局恢复。
- AI 入口与面板布局 1/1.5 倍、事务安装器共 5 项针对性 CTest 通过。
- 实机主托盘通知/Wi-Fi/声音/电源交替 11 次全程可见，位置保持一致，materialRenders 始终 10；Wi-Fi 和声音再点自身可收起；7 次快速切换后正常停在声音入口。

最初固定坐标脚本因托盘动态收起蓝牙而有点错入口的失败记录，不能用它判断路由结果；最终验收按实际控件位置执行。双击问题则由独立原生测试复现，已补齐处理。
