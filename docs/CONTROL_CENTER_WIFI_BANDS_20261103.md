# Wi-Fi 频段标注（2026-11-03）

用户要求列表标明 2.4 GHz 和 5 GHz。现在从 NetworkManager 的 Frequency（MHz）读取实际频段，显示为“网络名 · 频段 · 信号/连接状态”，悬停还能看到具体 MHz。不会根据 SSID 中的 5G、Wi-Fi5 等文字推断频段；缺少频率时显示频段未知，同时可正确标注 6 GHz。

去重键增加频段：同一 SSID、同一安全类型在 2.4/5 GHz 分开列出；同频段的多个接入点仍保留最强的一条，已连接的接入点优先。显示顺序继续保持已连接置顶、其余按信号降序，不按频段分组。点击沿用具体接入点路径；保存的连接若锁定另一个频段，不作为当前条目的可复用配置，不修改原配置。
