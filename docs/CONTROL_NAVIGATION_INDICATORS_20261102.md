## 子页切换

旧实现进入 Wi-Fi、蓝牙、声音、电源时直接重建页面，并在 340/440/520/660 像素的高度间切换。底部对齐造成标题和返回入口上下跳动，内容也直接替换。

现使用同一位置和尺寸的页面画布：标题及返回入口保持稳定，进入/返回采用相反方向的 14 像素轻移与 190 ms 淡入淡出。过渡只绘制两张已完成的页面快照，不逐帧重排控件、采样桌面或生成玻璃。新页面的网络行、蓝牙内容和电源操作先完成显示与布局，再生成目标快照，避免到动画结束才突然补上内容。

过渡期间暂缓后台状态应用，结束后恢复真实控件并释放两张快照；连续导航可从当前画面衔接，关闭会取消过渡并释放资源。减少动态效果模式直接切换。详情页预留状态提示空间，扫描完成不会再把列表撑高；返回主页时未完成的扫描提示不会挤动主页底部。短页面下方透明空白可点击收起。

原生窗口、焦点和预先捕获的场景继续复用。入口预加载、首帧实际滑条值、三块等宽布局和 Wi-Fi 自动扫描保留。

## 蓝点判定

蓝点确实有误判：OEM 的活动状态比较可能把固定启动器的占位窗口 ID `0` 与系统“没有活动窗口”的 ID `0` 判为相等。真实窗口数量大于零的固定组随后都被画成蓝色。

现直接核对系统活动窗口与组内非零的真实窗口 ID，规则为：

- 仅固定、未打开窗口：无点。
- 有窗口但在后台或最小化：灰点；多窗口维持灰色短线。
- 组内有真实前台活动窗口：蓝点/蓝线。

最小化窗口仍是已打开窗口，不会被当作未启动；固定占位项不计入窗口数量，也不会激活。
