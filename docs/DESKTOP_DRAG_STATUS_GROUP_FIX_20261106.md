# 桌面图标拖放与状态栏合并（2026-11-06）

针对录屏 `vokoscreen-2026-11-06_09-21-33.mp4` 中的拖放偏移、重复图标及黑色阴影反馈，并将系统托盘与温度、网速、日期合并为一个外框。

## 改动

- 文件原来把指针坐标作为控件左上角，系统图标则使用含文字控件的中心；现在统一以可见图标中心定位。
- 手动落格按实际像素距离选择空格，先保留未拖动图标的位置。移除按曼哈顿距离、行优先产生的方向偏好，以及文件列表顺序导致的邻居移位。
- 拖动期间原位置不再重复绘制图标；Qt 原生拖动预览增加无阴影标志，结束后恢复原控件绘制。文件管理器的跨窗口拖放继续使用原生 Xdnd。
- 共用祖先控件上的透明背景绘制一个边框，托盘、温度、网速、日期之间三条分隔线。原生托盘按钮、日历和 AI 按钮保留原父级和交互；关闭紧凑系统控件仍能恢复独立日期框。
