## 资源口径和结果

PSS 是按共享比例分摊后的常驻内存，避免把每个 Qt/WebEngine 进程的 RSS 直接相加。CPU 100% 表示一个核心。实机空闲采样使用当前用户进程及其后代；按需组件不由采样器启动。UI 测试不启动模型推理或对用户资料触发建库。

快捷设置在本机实测，更新前打开调用约 **343–387 ms**、打开后 **185–206 MiB PSS**。更新后的连续 12 次测试大多约 **16–20 ms** 开始显示，GPU 材质下约 **58–65 MiB**，隐藏后约 **44–49 MiB**，空闲退出后为零。前后场景内容并非固定的像素基准：旧实现还会解码 6912×4320 壁纸，新实现只保留实际弹窗区域；这是架构改变带来的有界开销。动画完成时间与首次显示时间分别计算。

着色器启用 Qt 二进制缓存，控制中心短期复用一个程序；每张卡片只在首次出现或几何/场景变化后渲染。真实 GPU 验证中，消除了每次打开重新花费约半秒编译的行为；缓存后首次卡片约几十毫秒，其余通常几毫秒。

完整 Peony 管理器含浏览器子进程，隔离测试约 **184 MiB**，实机约 **234 MiB**；原生 Peony 扩展设置页实机约 **32 MiB**。因此完整管理器保留为按需入口；已实测关闭后四个 UI/浏览器进程全部退出。AI 空间隔离空资料 UI 的打开/最小化没有持续 CPU 工作，但不代表真实资料建库没有成本。

实机部署前 15 秒样本：Fences（五个小组件及助手进程）约 227 MiB / 2.67% 单核；任务栏约 253 MiB / 0.66%；开始菜单约 125 MiB / 0%；AI 小站约 75 MiB / 0%；输入法前端约 103 MiB / 0%。这些是当前壁纸、目录、字体与会话下的观测，不是固定配额。
