# 低开销特效：FTG340 本机评估与实现

## 范围

这是独立代码副本，未安装到当前运行的桌面。保留原有内容、文字、图标、颜色规则和布局，只在控制中心中加入两项轻量反馈：

1. 固定玻璃卡片内部滚动列表的上下边缘渐隐。
2. 按钮按压时的局部轮廓微缩与高光，文字和图标保持原来的绘制。

实时背景折射、持续环境染色、整块玻璃形变不包含在本次实现中。原有弹层动画沿用现有实现。

## 硬件与判断

本机为飞腾 Phytium-D3000M HL8-C，8 核，约 27.1 GiB 内存；初始检查可用内存约 13.0 GiB。当前 KWin 报告 Phytium FTG340，OpenGL 4.6 V1.3.1，已启用 OpenGL 合成；屏幕 2880×1800、60 Hz。

这足以支持少量事件驱动的局部绘制，但不意味着全桌面实时折射没有代价。本轮要求是空闲不引入持续工作，同时约束交互时的增量；无法保证绝对零 CPU 或零内存。

初始 6 秒采样中，整机忙碌约 24.2%，KWin 约占一个核心的 25.2%。这是当时的活动负载，不是纯空闲值，也不是新代码的负载。

## 实现约束

- 按压反馈复用按钮原来的绘制表面和原生 QStyle 状态；不增加透明子窗口、不截取按钮图像、不修改点击区域。轮廓更新最多约 30 次/秒，按下 90 ms、释放 130 ms；到达稳定状态后停止计时。尊重系统减弱动画设置。
- 两条渐隐带各高 12 逻辑像素，作为滚动框的兄弟覆盖层，避免进入滚动内容的子层并破坏 Qt 的滚动优化。忽略鼠标事件，滚动与点击仍由原控件处理。
- 渐隐带只取用现有玻璃背景缓存。新增 `NativeGlass.cached()` 只读接口，不触发截图、模糊、着色器或材质重建。每个边缘只缓存自身窄条图像；尺寸/背景变化时失效，隐藏时释放。
- 没有新常驻进程、后台轮询、网络请求或空闲帧循环。网络/蓝牙/音频新行只在创建时附加反馈对象，不在每次状态采样时重新扫描全界面。
- 本次初版的额外按压覆盖层已被淘汰，最终代码使用按钮本身的绘制通道。

## 本机增量测试

使用同一进程、同一预热后的 Qt 窗口前后对照，30 行列表；测试实际 DPR 约 1.561。滚动驱动约 60 次/秒，按压约 4 次/秒。材料是确定性的缓存替身，以隔离新增效果成本；不包含真实系统服务轮询、后台应用波动，也不等价于实际桌面的 GPU 占用或帧率保证。

| 项目 | 最终测量 |
| --- | --- |
| 稳定空闲新增绘制 | 0 次 |
| 空闲 CPU 增量 | 未检出增加，毫秒级差异属于噪声 |
| 连续滚动 CPU 增量 | 约 4.98% 单核，即 8 核总容量的 0.62% |
| 连续按压 CPU 增量 | 约 2.42% 单核，即 8 核总容量的 0.30% |

| 对照场景材质烘焙次数 | 始终 1 次，没有因特效新增烘焙 |

用于本次筛选的工程预算：空闲额外绘制为零、交互增量低于本机 8 核总容量的 1%、额外 PSS 小于 1.5 MiB。该预算是本次实现的筛选标准，不是“完全不占资源”的承诺；当前测量通过。

## 验证

最终通过 105 项检查：6 项新增效果测试、91 项控制中心回归、7 项真实映射画面回归、1 项打包导入检查。画面回归使用私有 Xvfb/D-Bus、已有原生玻璃桥与 CPU 回退，检查局部更新与完整绘制一致，以及展开、切页、长列表滚动不增加材质烘焙。修复并覆盖了状态提示标签委托卡片绘制的兼容路径。

运行测试，不运行安装器：

```bash

  xvfb-run -a -s '-screen 0 2160x1350x24' dbus-run-session -- \
  /usr/bin/python3 code-work/ukui-liquid-desktop/apps/kylin-lqui-settings/tests/test_low_cost_effects.py \
```
