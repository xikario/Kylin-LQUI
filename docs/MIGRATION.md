# 统一源码仓库迁移

从 2026-11-01 起，Kylin-LQUI 使用一个源码仓库。首次导入包含当前工作树的已验证修改，不复制旧 Git 对象库、工作树管理信息或其他项目历史。

保留 `code-work/` 和 `peony-manager/` 的目录关系，避免破坏现有 CMake 相对依赖。源码由以下现役模块组成：主桌面框架、AI 小站、液态输入法及其兼容公共库、AI 空间和 Peony 管理器/扩展。历史研究仓库、SDK、备份和个人数据不进入发布树。

旧仓库可以归档为只读历史；不要删除旧安装版本或把清理源码等同于删除用户配置。当前桌面继续使用用户目录下已安装的版本，不依赖新仓库的 `.git`。后续开发以本仓库为准，再通过组件安装脚本部署。

部分历史验收文档引用本机证据路径，这些属于旧记录，公开仓库不包含个人桌面截图和运行日志。当前可复现的公开验证入口见 `docs/RELEASE_CHECK_20261101.md`。
