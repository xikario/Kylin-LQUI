# 2026-11-01 发布前修复与验证

## 后续更新（截至 `10f4f90` 的历史状态）

- 快捷设置底部日历入口按用户要求移除；不能将早期日历测试通过视为全面验收完成。
- 快捷设置复用开始菜单 CPU 折射与壁纸采样，缺少桥接库时为磨砂降级；可见卡片左沿对齐任务栏快捷按钮块最左沿。
- 开始菜单连点时继续修正 Dock 布局；新复现错误 Paint 从 182 次降为 0 次，保留居中宽度与组合区域。

## 首次发布四项复核（历史）

- 日历固定横坐标，从 Dock 上方的下偏移位置向上进入；减少动画模式直接定位。保留原生农历和日程。
- 同一应用的任意窗口激活，都更新共用图标下方横线；单窗口圆点、多窗口横线。
- 说明气泡使用透明圆角窗口和中性背景，不再露出四角底板或彩色描边。
- 隐藏的统一设置表单不再阻止 AI 小站失焦收起。置顶、截图和可见设置仍受到保护；取消置顶后重新安排自动收起。

## 保留的前轮修复

Wi-Fi 列表原位更新、固定阅读区；长通知可滚动阅读全文；主按钮有清晰按下反馈；快捷设置以模糊缓存提供液态边缘，并保持正文对比度。Dock 居中宽度与温度/带宽/日期组合没有被这些修复改动。

## 已运行的验证

- 控制中心 20 项交互回归，包含气泡透明角点与独立配色。
- AI 小站 CLI UI 在 100% / 150% / 200% 三个缩放比例下全套通过；新增隐藏设置表单与取消置顶的自动收起用例。
- 真实 OEM Panel 在独立 X11/D-Bus/配置下通过：日历可见轨迹仅沿 Y 轴向上；逐一激活三个同组窗口均更新横线；关闭组首窗口后入口接续；拥挤缩小、快速空白连点、托盘恢复、正常退出仍通过。
- 实机更新保留 AI 对话与草稿；实际失焦收起检查通过。

测试程序位于对应组件 `tests/`，运行方法参见 [BUILD.md](BUILD.md)。个人桌面截图、会话数据和本机运行日志不在公开源码内。

## 仍然保留的边界

正式登录接管尚未默认启用；原生 UKUI 基础服务保留。Codex 登录态听写兼容性仍有限制，不把 API 或本地模型方案冒充原生登录态听写。不同 GPU、OEM Panel 版本和长期负载需要持续验证；当前通过不等于所有国产硬件已完成认证。
