# Peony 菜单排序与标签合并 v1.1.0

发布日期：2026-11-04。Git 标签：`peony-window-tools-v1.1.0`。这是 Kylin-LQUI 中 Peony Window Tools 组件的独立小版本，组件与 DEB 版本为 `1.1.0`，其他应用保留各自版本号。

## 本次更新

### 调整刚刚打开的右键菜单

在 Peony 中右键文件、文件夹或空白处，点击“自定义菜单顺序…”，编辑器展示的就是刚才那份菜单，名称、图标和当前顺序逐项对应。支持拖动排序以及上移/下移；灰色不可用项目仍可调整位置，子菜单作为整体移动。

空白处、文件夹、不同文件类型、多选文件夹和多选文件的菜单分别保存，互不影响。保存后下一次打开同类菜单生效；“恢复此菜单默认顺序”只清除当前类型的排序。入口放在实际右键菜单里，统一设置不增加全局排序总表。

### 将多个窗口的标签合并到当前窗口

新增“合并所有标签到此窗口”。当前窗口标签保持在前，其他窗口的标签依次追加，重复目录保留；只有一个窗口时入口置灰。

每个标签按地址重新打开，核对目标标签的地址与数量后才关闭可安全关闭的来源窗口。遇到无效地址、加载超时、接口不匹配或合并期间标签变化时停止，并保留尚未处理完的来源窗口。带有嵌入 CLI 终端会话或拒绝关闭的来源窗口会保留并提示。

来源标签的前进/后退历史、选中项不迁移；独立进程、独立 D-Bus 会话和桌面窗口不参与合并。

## 获取和升级

发行版附件提供：

- `peony-window-tools_1.1.0_arm64.deb`：ARM64 的 Peony 扩展安装包；
- `peony-window-tools_1.1.0_arm64.deb.sha256`：安装包校验文件；
- GitHub 自动生成的源码 ZIP / tar.gz。

已验证环境为银河麒麟 / UKUI X11、ARM64、Qt 5.12、Peony 3.26。插件按当前宿主的 Peony 接口元数据构建；其他版本、架构和发行版未作为本次二进制兼容承诺。

将 DEB 和校验文件放在同一目录，在该目录执行：

```bash
sha256sum -c peony-window-tools_1.1.0_arm64.deb.sha256
sudo apt install ./peony-window-tools_1.1.0_arm64.deb
```

安装包只更新系统扩展及随包文档，没有自动重启文件管理器的维护脚本。安装完成后需要完整退出并重新启动 Peony 进程，才能加载新版插件；仅关闭一个窗口再打开可能仍复用旧进程。退出前先完成文件任务并处理嵌入 CLI 会话，避免中断工作。

若插件被用户禁用，可在 Kylin-LQUI 设置 → 文件管理与扩展 → Peony 扩展中检查“菜单排序与标签合并”的启用状态。旧版独立 `peony-menu-order` 编辑器不再随本版提供。

## 配置与恢复

排序配置为 `~/.config/peony-manager/menu-order-contexts.json`，遵循应用的 XDG 配置根。文件通过锁和原子替换保存；损坏的已有配置不会被静默覆盖。旧版全局排序文件保留，不自动套用到本版分类菜单。

只想恢复某类菜单时，在对应右键菜单的排序编辑器中使用“恢复此菜单默认顺序”。停用插件可在扩展设置中操作；卸载该独立包可执行 `sudo apt remove peony-window-tools`。卸载保留个人排序配置，已加载的进程仍需正常重开才能移除内存中的扩展。
